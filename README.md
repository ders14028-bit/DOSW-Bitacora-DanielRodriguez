# 📘 DOSW Bitácora 

Este repositorio contiene mi **bitácora de aprendizaje y desarrollo** durante el curso de **DOSW**.

La bitácora documenta el progreso semanal del curso, incluyendo **ejercicios, implementaciones, patrones de diseño, prácticas y reflexiones técnicas**.

---

# 🗂 Estructura del Repositorio

El repositorio está organizado por **cortes académicos**, y dentro de cada corte se encuentran las **semanas correspondientes**.

Cada semana contiene su propio **README** donde se documenta:

* Temas estudiados
* Ejercicios realizados
* Implementaciones de código

# 🧠 Objetivo de la Bitácora

El objetivo de esta bitácora es:

* Documentar el **progreso semanal del curso**
* Consolidar conceptos de **arquitectura y diseño de software**
* Registrar **implementaciones prácticas**
* Servir como **referencia futura de aprendizaje**

---

# 🛠 Tecnologías Utilizadas

Durante el desarrollo del curso se utilizan principalmente:

* **Java**
* **Maven**
* **JUnit**
* **JaCoCo**
* **Git / GitFlow**
* **IntelliJ IDEA**
